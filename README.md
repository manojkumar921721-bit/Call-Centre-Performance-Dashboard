# Call Centre Performance Dashboard | Excel (2026)

An Excel dashboard built to analyze call centre performance, track key metrics, and compare representative activity and customer ratings.

## Dashboard Preview

![Call Centre Performance Dashboard 2026](images/call-centre-dashboard.png)

## Project Overview

This project focuses on analyzing call centre data using Microsoft Excel. The dashboard brings together key performance indicators, monthly call trends, representative comparisons, and customer ratings in a single view.

The aim was to make the data easier to understand and compare through charts, summary metrics, and a structured dashboard layout.

## Dashboard Highlights

- **KPI Summary:** Overview of total calls, total amount, duration, average rating, and happy callers.
- **Monthly Call Trends:** Visualizes call activity throughout the year.
- **Representative Performance:** Compares call volumes and amounts across representatives R01–R05.
- **Caller Analysis:** Compares female and male callers across Cincinnati, Cleveland, and Columbus.
- **Customer Ratings:** Displays the distribution of customer ratings.
- **Detailed Performance Report:** Provides a representative-level breakdown across locations.
